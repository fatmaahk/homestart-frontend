- Homepage layout & navigation
- Interactive Category Explorer (React state)
- Featured Furniture section

- Responsive design

Stack: React + Vite + JavaScript + CSS

Assigned SDG: SDG 1 – No Poverty

```bash
npm install
npm run dev
```

- Responsive breakpoints for tablet and mobile
- Colour contrast using the agreed group palette
